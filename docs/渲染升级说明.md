# 实时渲染升级

日期：2026-11-13。

本次目标是改进现有可交互三维画面的材质、光照和观察视角。家具位置、尺寸、预算与Agent接口保持原有数据结构。

## 已做修改

- 房间材质：用Poly Haven的wood_floor与plastered_wall颜色、OpenGL法线、粗糙度图替换手绘地板和纯色墙面。地板颜色为2048像素，其他地图为1024像素。UV按世界米制设置，调整房间尺寸时维持纹理比例。
- 织物：使用fabric_pattern_07的法线与粗糙度纹理，保留中性米色，不使用其红色花纹颜色图。
- 灯光：增加lebombo HDR经PMREM预过滤提供环境反射与漫反射；降低均匀补光，设置朝向窗口的日光和窗口面光源，提供自然/暖调两个预设。HDR不可用时保留基础环境光。
- 渲染：显式sRGB输出与ACES色调映射，精细模式使用GTAO、Poisson降噪、多重采样渲染目标；流畅模式直接渲染，减少GPU负担。缺少浮点颜色缓冲扩展时使用基础渲染并提示。未测得帧率，不承诺特定性能。
- 视角：增加1.6米初始相机高度、60度视场的室内视角；保留全景观察、俯视和二维兼容。
- 资源：保留原家具GLB及其校验和，调整纹理各向异性过滤以改善斜视纹理。房间资源和模型缓存按生命周期释放。截图和保存快照经过当前的渲染管线。

## 来源与复现

10个新增原始文件约9.6MB，均在`public/render`中；包括保留的织物原始颜色文件，当前没有用于场景。来源、下载地址、CC0声明、字节数、SHA256及原始MD5记录在`manifest.json`。通过公开API获取，下载器使用独立User-Agent并检查原始MD5。

运行`python scripts/fetch-render-assets.py`可校验或重新获取所选文件；普通启动使用已下载资源，不访问Poly Haven API。

官方技术与许可依据：[Poly Haven许可](https://polyhaven.com/license)、Three.js随依赖提供的GTAOPass、OutputPass、HDRLoader和EffectComposer源码。新增测试检查资源哈希、HDR可解码性，以及不同宽度墙体的UV比例。

## 验收边界

已检查原始GLB中的颜色、法线和金属度/粗糙度贴图，未以通用材质覆盖它们。此升级不增加家具几何精度或纹理分辨率；目录缩略图仍是此前的未贴图几何预览。真实商品仍是尺寸示意模型。

当前没有烘焙全局光照、路径追踪或实测光照参数，不表示与真实房间的照片一致。浏览器工具连接超时，尚未取得修改前后的实际WebGL截图，也未完成GPU端显示和性能验收。

验证记录：TypeScript检查和生产构建通过，23项自动化测试通过；原5174服务已更新；30件模型、30张目录预览及10个新增渲染资源的HTTP与哈希检查通过；Agent八步HTTP演示回归通过。以上不代替浏览器端视觉验收。

验收建议：刷新原地址，观察木纹和墙面细节，切换室内视角及两种光线；切换精细/流畅查看接触遮蔽变化；拖动并旋转家具，修改房间尺寸，切换俯视及二维后返回；截图、保存并恢复方案，确认材质仍正确且无报错。

## 第二轮光影与材质改进（2026-11-14）

参考宜家公开的物理材质与光照方向，在现有实时管线中增加以下能力，未复刻其专有技术，也未新增照片合成或真实房间光照估计。

- 房间表面升级为MeshPhysicalMaterial；木地板增加可切换的清漆层和粗糙度，地毯增加织物sheen响应。保留原颜色、法线和粗糙度地图；精细家具GLB的原始材质保持不变。
- 光线分为自然日光、暖调光线、夜间室内光。夜间关闭日光，使用室内聚光源及较低的窗口和环境补光；暖调模式增加室内补光。背景随光线改变。属于可调预览，没有实测照度标定。
- 改用支持radius的PCF阴影过滤；调整阴影偏移，并让日光阴影视锥随房间尺寸变化，减少固定大范围阴影图浪费。阴影强度同时控制直接阴影和精细模式下的GTAO遮蔽；流畅模式保留直接阴影。
- 场景左上角新增“光影与材质”展开面板，可调整亮度、日光强度、阴影强度、地板清漆/哑光及墙面暖白/米灰/浅绿，支持恢复默认。夜间日光滑块禁用。设置单独保存至当前浏览器，刷新或切换二维后返回时恢复；不会变更方案尺寸、家具、预算或Agent请求。
- 真实商品的通用尺寸代理增加圆角、坐垫和材质细节；克隆房间的织物/木材材质作为通用视觉示意。没有获取精确SKU模型，颜色和外观仍不得代表实物。外包围盒保持官方长宽高，底部接地，避免影响几何校验。

新增测试覆盖损坏或异常预览设置的恢复，以及全部4件可放置真实商品的长宽高、接地和材质克隆隔离。自动化测试共25项通过。浏览器连接仍超时，没有取得实际画面的前后对比和性能测量；GPU渲染、滑块变化及夜间效果需要实机验收。

相关依据：[Three.js MeshPhysicalMaterial](https://threejs.org/docs/pages/MeshPhysicalMaterial.html)、[LightShadow](https://threejs.org/docs/pages/LightShadow.html)，实现参数以项目锁定的Three.js 0.181版本源码为准。
