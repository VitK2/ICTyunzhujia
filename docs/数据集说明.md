# 云筑家工程数据集 v0.1

这是一套用于三维家具展示、检索、布局接口和几何校验的初始工程数据。它不是实际在售商品库，也不是已经训练/评测过模型的研究数据集。

先读 [采集处理方案](PLAN.md)，再查看 `reports/geometry_contact_sheet.jpg` 和 `metadata/catalog.csv`。

## 本轮结果
- 31件Poly Haven候选素材中30件通过处理，1件比例异常隔离（见构建报告）。
- 30件GLB：沙发5、座椅5、茶几7、边几3、床头柜1、柜体5、置物架4。
- 12个明确标记为合成的客厅；48个几何回归案例；40条中文需求解析样例。
- 官方glTF验证报告、文件SHA256清单、原始下载和来源元数据。
- 真实商品绑定模板30行，仅预填资产ID；价格、品牌、SKU、购买链接均为空。
- 另有5条宜家中国官方商品事实记录（沙发、扶手椅、茶几、电视柜、墙搁架），包含型号、商品尺寸、参考价、来源与采集时间；均未绑定精确三维模型。价格非实时承诺，未选择门店检查库存。没有下载商品图片。

## 目录
```

processed/models/    纹理嵌入、Y向上、底部中心原点的GLB
processed/previews/  自行生成的无纹理几何预览

fixtures/            合成房间、几何测试案例、中文需求样例
reports/             构建、格式、数据一致性、样例验证和可视化报告
licenses/            素材许可和API使用条款的来源证据
scripts/             可重跑的下载、处理、生成、验证脚本
```

## 字段与坐标
- `asset_id`：稳定内部ID；`source_url`是素材页面，不是商品购买页。
- `width_mm/height_mm/depth_mm`：标准化后X/Y/Z轴包围盒，毫米。glTF按米解释，保存上游dimensions，排序比较避免猜测上游轴顺序。
- 模型Y轴向上、底部中心原点，右手坐标。房间使用X/Z地面坐标、左下角为(0,0)，南墙为Z=0；业务单位毫米。
- `normalization_translation_m`：仅平移的处理记录，`normalization_scale=1`，保留比例和原PBR材质。
- `dimension_basis`：模型几何尺寸，不是厂商量测。`dimension_review_status`一致仅指与上游数值基本吻合。
- `front_yaw_deg=null`：未猜测正面，后续需人工标注，90度转向可能改变宽深方向。
- `category`：按源名称人工粗分；风格未自动猜测。摇椅/休闲椅暂归armchair，部署时可细分。
- `commercial_binding_status=unbound_asset_not_retail_product`：不能将这些素材称为商品精确模型。
- `price_fen=null`及`purchase_url=null`：不得当作零元商品，也不能用于真实购买预算评估。
- 每件资产保存作者、标签、原始文件地址、下载日期、MD5与SHA256。

## 复现
在项目根目录使用Python 3.12与Node.js。Python包见requirements.txt；本轮trimesh为5.2.0，官方glTF验证器为2.0.0-dev.3.10。
```
python -m pip install -r dataset/requirements.txt
python dataset/scripts/bootstrap_validator.py
python dataset/scripts/build_dataset.py
python dataset/scripts/make_fixtures.py
node dataset/scripts/validate_glb.cjs
python dataset/scripts/render_textured_samples.py
python dataset/scripts/collect_retail_seed.py
python dataset/scripts/verify_dataset.py
```
本轮额外Python工具装在项目`.dataset_tools`，没有改系统Python依赖。脚本兼容该位置及正常虚拟环境安装。下载使用唯一User-Agent和最多3并发；已有文件MD5匹配则复用。不要将下载成功数量当作最终可用数量。

## 质量与局限
查看`reports/gltf_validation_summary.json`中的实际错误和警告。当前警告主要为上游缺少切线，浏览器可能运行时生成；不应声称跨浏览器PBR观感已验证。

几何预览已查看；`basecolor_samples.jpg`只采样基础色，用于确认代表性贴图可读，不是完整PBR渲染。尚未在产品浏览器中逐件验收正面、法线效果和使用朝向。

`steel_frame_shelves_01`的几何与上游尺寸约相差10倍，原始资料保留，未进入可用catalog和processed模型；没有凭猜测自动缩放。

房间和案例为程序构造；案例覆盖轴对齐占地、重叠、越界和90度门扇扇形，不覆盖旋转家具、通道净宽、柜门、采光或专业装修规范。生成器和检查器同属开发工具，通过不等于生产布局算法通过独立评测。

需求样例为模板合成，按模板族划分development/heldout_template；房间按ID组分development/heldout_fixture，未作为训练/测试性能报告。留出文件在开发中已可见，不能宣称盲测。预训练模型的既有数据接触情况未知。

## 来源与许可
素材来自[Poly Haven](https://polyhaven.com/)，作者见catalog；资产许可[CC0](https://polyhaven.com/license)。通过[官方API](https://polyhaven.com/our-api)获取并保留来源。API条款与素材许可分别记录，网站文本和元数据不额外宣称为CC0。没有将第三方网站截图或预览图打包为本项目资产。

真实商品种子表来自表内列出的宜家中国官方商品页，事实记录与CC0资产分开保存；未采集图片或三维商品媒体，不宣称宜家页面、商标或产品设计为CC0。墙搁架`mount_type=wall`，不能套用落地家具布局规则。商品尺寸不等于包装尺寸，脚本保留原字段名及简短尺寸依据，长度/宽度型桌面映射为本项目width/depth。


## 2026-11-17：ABO 家具与 ambientCG 材质接入

本轮从 Amazon Berkeley Objects 官方 S3 下载 86 件家具模型及配套商品预览图，85 件通过几何与尺寸核验并进入 `public/data/abo.json`。1 件壁挂柜保留原始文件并隔离，不进入落地家具目录。分类：沙发18、休闲椅18、茶几14、边几14、电视柜8、置物架8、储物柜5。新增可用 GLB 合计约143.4 MiB。与原有30件Poly Haven模型和5条宜家事实记录合并后，界面共120条记录，其中115条有独立贴图模型。

原始目录、元数据、模型和预览图缓存在 `.local/abo/`；可分发模型、预览图分别在 `public/models/abo_*.glb` 与 `public/previews/abo_*.jpg`。每件记录保留来源、ASIN、品牌/颜色/材质等原始属性、许可证、原始及处理后SHA256、字节数、处理说明和几何核验状态。商品名称和属性来自历史数据，不推断当前在售、售价或库存，价格保留为空。ABO模型与商品图片按CC BY 4.0署名；详见 `public/credits.html` 与 `public/licenses/abo/`。

处理仅将嵌入纹理缩小到最大1024像素，并用根节点将模型接地、居中、从上游+Z正面转向本项目-Z正面；几何、UV和PBR材质参数保留。尺寸取模型几何包围盒，与上游各轴尺寸容差2厘米核对，不等于厂商量测或承诺。`scripts/verify-abo.mjs`可复核；隔离与核验明细见 `.local/abo/geometry-report.json`。通过几何检查不代表85件均已逐件人工视觉验收。

从ambientCG下载WoodFloor051和Fabric030的1K JPG原始压缩包，并提取基础色、OpenGL法线、粗糙度共6张贴图。原包与API元数据在 `.local/ambientcg/`，运行贴图在 `public/render/`，来源、CC0许可、哈希和尺寸记录在 `public/render/ambientcg-manifest.json`。界面“光影与材质”可在新旧地板与织物间切换；ABO家具保留自身原始贴图，不使用通用材质覆盖。

Agent在原有推荐、尺寸校验和布局流程中读取ABO商品目录及属性，能按颜色、材质等已有证据检索。未知价格不当成零元；设单件硬性价格上限时不采用无价商品。手动估价在预算中单独计入。

复现命令（Python需Pillow，Node需22.18以上，并已安装项目依赖）：
```
python scripts/import-abo.py metadata
python scripts/import-abo.py models
node scripts/verify-abo.mjs
python scripts/import-ambientcg.py
```
ABO下载选择与验证阶段会分别输出报告，壁挂隔离为预期的拒收项。下载和处理脚本均保留来源缓存，减少重复下载。


本轮验证结果：58项自动测试通过，TypeScript类型检查与Vite生产构建通过。`scripts/check-expanded-assets.mjs`已使用本机真实DeepSeek接口完成新增家具推荐、多轮选第一款替换、保留锁定沙发与其他家具、阅读布局更新；最终基础几何问题为0。178个新增模型/预览图/材质/许可文件通过HTTP可访问性检查，联调记录保存在 `.local/expanded-assets-report.json`。浏览器已实际操作ABO布艺休闲椅的推荐及替换，显示原始贴图模型，并验证自然日光、地板材质和新旧地毯织物切换。上述为当前样本和合成房间联调，不表示全部模型经过人工逐件验收，也不构成实际装修或预算保证。
