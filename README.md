# 从仓库启动云筑家

准备 Node.js 22.18 或更新版本和 pnpm 11.25.0。在仓库根目录运行：

```powershell
pnpm install --frozen-lockfile
pnpm test
pnpm build
node scripts/serve.mjs 5174
```

打开 http://127.0.0.1:5174/ 。应用素材随源码提供。首次运行使用默认演示模式。需要接入云模型时，按 `.env.example` 在本机配置 `.env.local`。

以下是本地交互版的项目说明。仓库版首次启动前需要完成上述构建步骤。

# 云筑家 本地交互初版

面向华为ICT创新赛方案的三维家具布置原型。所有运行素材、代码与说明均位于此目录，无需依赖原C盘数据目录。

## 使用

运行需要Node.js 22.18以上（建议24以上）。开发时安装pnpm，在此目录运行：

```
pnpm install --store-dir .local/pnpm-store
pnpm start
```

另开终端运行前端开发服务：

```
pnpm dev
```

开发地址默认 http://127.0.0.1:5173 。已附构建后的`dist`，直接双击`启动云筑家.cmd`即可使用，不需要重新安装依赖。启动器等待后台服务就绪后才打开网页，默认地址为 http://127.0.0.1:5174；端口被旧版本或其他程序占用时自动尝试后续端口。请使用启动器实际显示的地址，或打开其生成的`Open-YunZhuJia.url`。重复启动会复用相同构建的服务；关闭启动窗口不会停止后台服务。

如果三维视图初始化失败，会自动显示可拖动布置的二维兼容视图；也可在页面上主动切换「二维兼容」，或在访问地址后加`?mode=2d`。页面脚本和目录加载失败会给出错误说明，不再只有空白或无限加载。启动日志保存在`.local/server-端口.log`及`.local/server-端口.error.log`，最近的实际地址见`.local/launch.json`。

```
pnpm test
pnpm build
pnpm preview
```

构建后的前端位于`dist`；Agent接口由Node后端提供，完整应用请使用启动脚本或`pnpm start`。`pnpm preview`仅预览前端，不提供Agent接口。开发服务默认将`/api`代理至5174，若后端使用其他端口须相应修改`vite.config.ts`。页面使用浏览器WebGL；请使用Chrome或Edge。模型与字体均不依赖外部CDN。网页需要HTTP服务，不能直接双击index.html。`scripts/serve.mjs`仅监听127.0.0.1；前台运行时按Ctrl+C停止。

## 实时渲染

三维场景已接入本地PBR木地板、灰泥墙面、织物细节和HDR环境光。木地板颜色贴图2K，其他贴图及HDR为1K；保留家具GLB内的颜色、法线与粗糙度材质。新增「室内视角」（相机初始高度1.6米）、自然/暖调光线和精细/流畅画质。精细画质增加GTAO接触遮蔽、降噪与多重采样；流畅模式保留材质、环境光和基础阴影。截图与方案快照使用当前渲染效果。

新增材质均来自Poly Haven的CC0原始资产，文件、来源与校验和见`public/render/manifest.json`；下载脚本为`scripts/fetch-render-assets.py`。织物仅采用法线与粗糙度细节，颜色使用中性米色。所有资源本地提供，不依赖运行时外部CDN。

当前仍是实时近似渲染，没有烘焙全局光照或光线追踪；5条真实商品仍为尺寸示意模型，外观不代表商品实物。浏览器画面与性能尚需实际设备验收。详细记录见`docs/渲染升级说明.md`。

第二轮已加入夜间室内光、地板清漆/哑光、织物光泽及墙面配色，展开场景左上角「光影与材质」可调整亮度、日光与阴影强度。预览设置单独保存在当前浏览器，可恢复默认；导出的方案JSON仅包含布局，不包含这些预览设置。真实商品尺寸代理增加圆角与坐垫，仍不是商品精确外观模型。

## Agent接入与配置

右侧新增「我的选购与布置需求」，可保存预算、住房城市/区域、家具偏好、生活需求、布局重点和选购范围；需求随方案保存与JSON导出。保存后发送「按我的需求推荐沙发和茶几」，推荐卡片列出名称检索、尺寸外框、历史价格等依据和待核验条件。可选择「加入并布置」或「替换同类家具」，通过预算、空间及锁定检查后应用；仅推荐不会自动移动家具。详情见`docs/需求推荐与DeepSeek演示.md`。

2026-11-16已完成DeepSeek真实API联调。右侧「模型配置」支持密码输入、保存并测试连接、保留原密钥及切回演示模式；密钥仅保存到本机后端读取的`.env.local`（未加密、已被Git忽略），不返回页面或写入浏览器持久存储。连接状态与当前配置绑定，服务重启后需重新测试。用户已在界面配置，当前为cloud模式。真实推荐、阅读布局修改和推荐茶几应用均通过，记录见`docs/DeepSeek真实联调记录.md`。

已接入后端工具调用流程。未配置时默认`demo`模式使用固定规则规划工具；`cloud`模式由真实模型选择工具、读取执行结果并继续调用。DeepSeek优先使用界面配置，华为云MaaS等兼容服务可通过本地`.env.local`配置；完整说明见[Agent接入说明](docs/Agent接入说明.md)。

可先在右侧发送「预算8000元，保留沙发，茶几换小一点，留出活动区，生成阅读方案」，展开工具执行记录查看实际结果。候选通过最终几何检查、数据校验和锁定检查后才应用；模型超时、轮次耗尽或最终检查不通过均不应用候选。处理期间若手动修改了场景，客户端不会用旧候选覆盖新场景。

## 操作

点击家具卡片添加；在三维场景直接拖动家具。拖动空白旋转视角，滚轮缩放。选中家具按R旋转、Delete删除，Ctrl+Z撤销。锁定后不能手动移动、旋转或删除，布局建议也会保留。

建议先保存初始方案，再用不同布局偏好调整并保存第二套，点击“对比已保存方案”。方案与快照只保存在当前浏览器，请导出JSON备份；清理浏览器数据会移除保存记录。

## 当前边界

这是本地原型。已实现兼容Function Calling的适配器，并通过真实DeepSeek API联调；华为云MaaS尚未联调。候选位置搜索和几何检查由确定性工具执行。尚未部署ECS、RDS、Redis或OBS，也没有训练模型；CodeArts开发记录和华为云部署需要独立完成。

素材来自Poly Haven，CC0，保持原始比例；尺寸为模型包围盒，家具正面朝向仍需人工复核。开放素材没有真实售价和商品绑定。手动估价只是用户输入，不是官方报价。未定价家具始终显示“未定价”，不判为零元。

5条宜家资料采集于2026-11-10，价格可能变化，门店库存未核对，商品链接可回官网核对。商品三维显示为按官方尺寸绘制的示意模型，不是精确外观；墙搁架暂不支持添加。

几何检查基于保守矩形占地及门扇扇形；不包含完整通道可达性、柜门开合、施工、水电、承重或专业装修规范。当前布局搜索是启发式，未找到候选不代表数学上绝对无解。预算由已知金额计算，未定价项目会提示缺口，助手不会自动编造售价。

## 代码

- `src/main.tsx`：工作台、目录、交互状态、规则助手、保存比较。
- `src/Scene.tsx`：Three.js房间、模型加载、光照、拖动与视角。
- `src/Plan2D.tsx`：不依赖WebGL的平面家具布置及截图。
- `scripts/launch.ps1`：Windows启动、端口检查、就绪等待及浏览器入口。
- `src/engine.ts`：数据类型、几何校验、预算汇总与布局搜索。
- `src/catalog.ts`、`src/plan-schema.ts`：前后端共享目录映射与方案格式校验。
- `server/agent.ts`、`server/tools.ts`：模型工具循环、工具白名单和候选事务。
- `server/api.ts`、`server/config.ts`：本机HTTP接口、配置读取和公开状态。
- `tests/agent.test.ts`、`scripts/check-agent.mjs`：Agent行为与HTTP集成检查。
- `tests/engine.test.ts`：几何与预算核心检查。
- `public/models`、`public/previews`、`public/data`：本地模型与资料。

运行依赖由`pnpm-lock.yaml`锁定；许可证证据与详细数据说明见`docs/licenses`和`docs/数据集说明.md`。
